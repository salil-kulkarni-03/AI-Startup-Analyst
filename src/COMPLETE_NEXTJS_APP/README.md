# Cereva - AI Startup Analysis Platform

## 🚀 Quick Start

1. Open this folder in VS Code
2. Open terminal (Ctrl + ` or Cmd + `)
3. Run:
```bash
npm install
npm run dev
```
4. Open http://localhost:3000

## ✅ Features Implemented

- ✅ Cereva branding with custom logo
- ✅ Purple gradient buttons throughout
- ✅ Clickable footer with contact info
- ✅ Upward pyramid before "How It Works"

## 📁 Structure

- `app/` - Main application pages
- `components/` - Reusable components
- `lib/` - Utilities and mock data
